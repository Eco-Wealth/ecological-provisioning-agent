# Public Repo Bootstrap Prompt

Build and iterate this repository as a brandless ecological provisioning kernel.

## Target

Make the repository demonstrate this local flow:

```text
messy ecological/civic intent
-> structured intent
-> principle lenses
-> stewardship route
-> work packet
-> proof checklist
-> receipt
-> truth-boundary validation
```

## Boundaries

Do not add brand-specific language, private credentials, transaction-signing actions, payment execution, labor dispatch, public posting automation, deployment automation, or certification claims.

The repo may add adapters only in read-only or draft/proposal mode.

## First pass priorities

1. Keep the SDK pure and dependency-light.
2. Keep CLI commands local and file-based.
3. Keep MCP tools local-first.
4. Keep examples small but real enough to test the loop.
5. Keep truth warnings visible.
6. Update receipts whenever the repo behavior changes.

## Stop condition

Stop when `pnpm build` succeeds and the CLI can produce a packet and receipt from the included examples.
