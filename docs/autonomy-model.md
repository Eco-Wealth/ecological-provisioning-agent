# Autonomy Model

Autonomy is staged.

## Stage 0: Local drafting

The system creates local packets, receipts, checklists, and warnings. No external action.

## Stage 1: Read-only adapters

The system can read public or permitted data and preserve source metadata.

## Stage 2: Draft proposals

The system can draft proposed posts, deployments, purchases, payments, or assignments, but cannot execute them.

## Stage 3: Human-approved execution wrapper

A private downstream wrapper may execute approved actions only after explicit human review, with receipts.

## Stage 4: Conditional autonomy

Only narrow, reversible, low-risk actions may run without per-action approval, and only after governance and audit controls exist.

This public kernel should remain at stages 0-2.
