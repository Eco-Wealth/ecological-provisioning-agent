# Repo Genesis Receipt

## Intended

Create a brandless public ecological provisioning kernel that can be dragged into a new GitHub repository.

## Built

- README, license, repo settings, docs, prompts, workflows, skill blueprints.
- JSON schemas for intent, lenses, routes, packets, proof, receipts, and adapters.
- TypeScript SDK with pure local functions.
- CLI package wrapping the SDK.
- MCP local tool-server stub.
- Static demo operator UI.
- Example inputs and outputs.
- GitHub issue and PR templates.
- CI workflow.

## Truth-boundary check

No private brand names, credentials, live payment, live dispatch, transaction signing, deployment, public posting, certification, compliance, endorsement, or verified-outcome claims are required for this public kernel.
